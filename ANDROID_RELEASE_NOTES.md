# Browser for Android v0.4.0

Type a query in the address bar to open Browser Search. Results show site names, titles, and snippets inside Browser, and tapping a result opens its website. Back and Forward restore cached results. Reload fetches fresh results.

Browser Search uses the [Mwmbl web search API](https://developer.mwmbl.org/). Mwmbl’s anonymous service allows up to 1,000 requests per IP per month and one request per second. The results page includes the provider credit and license.

## Install

Download **Browser-0.4.0-Android.apk** from the [Browser v0.4.0 release](https://github.com/culpen90/browser/releases/tag/v0.4.0). Browser supports Android 8.0 (API 26) or later. The APK uses version code 6 and the existing production signing certificate for in-place updates.
